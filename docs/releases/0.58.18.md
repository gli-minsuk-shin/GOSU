# GOSU 0.58.18 — candidate

Corrects the History renderer's native Calendar ID preservation for the 0.58.17 deep-link feature.
History scroll anchors use separate `jumpId` fields; native event IDs remain unchanged and legacy
snapshots without native IDs do not get guessed links. See [Briefing contract](../BRIEFING_WORKSPACE.md)
and [release procedure](../RELEASE_RUNBOOK.md).
