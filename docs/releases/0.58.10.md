# GOSU 0.58.10 — Briefing context export

Installed locally on 2026-09-09. This is an ad-hoc development build, not a notarized public release.

- Desktop Project Chat details can export a **reviewed, bounded project working-memory summary**
  as JSON. Raw chat is not exported. This is a manual snapshot, not automatic cross-app DB access.
- Standalone Briefing Lab adds optional native-LLM summaries/importance/relevance, encrypted
  user-reviewed memory, Scholar mail candidates, actual arXiv equations/figures and compact
  hourly weather graphics. Briefing Lab remains at port 4318, not embedded in the Desktop package.
- Mail reads and private analysis have separate native confirmation. This prototype is not a
  production-isolated mail broker; see the explicit security limitations in
  [Briefing intelligence](../BRIEFING_INTELLIGENCE.md).
- No automatic scheduler, private mailbox archive or provider fallback was enabled.

Implementation and operations: [maintenance](../MAINTENANCE_GUIDE.md),
[release runbook](../RELEASE_RUNBOOK.md).
