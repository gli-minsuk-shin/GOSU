## Changes and boundaries

- Reuses Desktop Crossref metadata normalization with the Briefing pinned-host transport.
  Concurrent arXiv/Crossref/OpenReview discovery, isolated 12-second per-provider search deadline,
  partial failure receipts and interleaved candidate coverage across providers.
- Explicit title/topic/recent semantics; default is topic, never inferred from word count.
  Known year filters evidence instead of relabelling it. Named-title/topic queries do not inherit
  recurring date/author/exclusion settings. The recurring collection pipeline is unchanged.
- DOI/Crossref and arXiv ID/URL direct identification; PMLR article URL remains supported.
  Publication dates never come from metadata deposit timestamps or invented month/day values.
  Dataset/book/non-article Crossref types are excluded; registered article metadata alone still
  does not prove a result is a relevant research paper or that full text is available.
- arXiv HTML first, title-verified public PDF fallback. DOI articles can locate a title/author-matched
  OpenReview copy or a DataCite-identified preprint; copies are not claimed to be identical versions.
  No arbitrary publisher fetching, authentication/challenge bypass or access guarantee.
- Bounded successful search caches: title/identifier 24h, topic 10m, recent 2m. Reading cache survives
  rediscovery of the same ID/title. No user settings, permissions, memory or stored library mutation.
