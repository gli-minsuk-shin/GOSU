## The Model Assistant's input row sat under the fold

Left open by 0.58.158 and recorded there as known: at the top of the page the chat panel hung past
the bottom of the window and the composer was cut off until you scrolled a little.

Measured in a browser rather than reasoned about. At a 900px window the panel began at **y=71** —
the shell's 10px top margin plus a 61px header — and was sized `calc(100dvh - 32px)`, which is the
height of a panel that begins at the _top_ of the page. It therefore ended 39px past the bottom.
The model list next to it never had the problem because it is a direct child of the shell and
begins at y=10, where that arithmetic is true.

So one number was written twice and only one of the two was right.

The header is now sticky at the shell's own top margin and holds a named height, and the panel's
`top` and `height` are both written in terms of that name:

```css
.model-lab-shell {
  --model-lab-header-height: 61px;
}
.model-lab-header {
  position: sticky;
  top: 10px;
  height: var(--model-lab-header-height);
}
.model-chat--sidebar {
  top: calc(10px + var(--model-lab-header-height));
  height: calc(100dvh - 20px - var(--model-lab-header-height));
}
```

The two cannot drift apart any more, which is the actual defect rather than the 39 pixels. The
header staying visible while the page scrolls is a side effect and a welcome one.

### Why a fixed header height is safe here, and how it was checked

The header is a three-column grid whose middle column is `minmax(0, 1fr)` — it shrinks rather than
wraps. Its height was measured at every shell width from 568px to 1408px and was 61px at all of
them, and its three children are 34, 29 and 44px tall, so nothing is clipped by holding it there.

### What was considered and not done

Turning the shell into a fixed-height app layout, with only the graph column scrolling, is the
tidier answer. It would also move the React Flow canvas, the module inspector, the model list and
every stacked and focus-mode rule at once, for a defect that is one arithmetic mistake. The narrow
fix is the one that matches the fault.

Left alone deliberately: `.graph-workspace` carries its own `calc(100dvh - 76px)`, tuned separately
from the panel's numbers and 5px apart from them. Folding it into the same variable would change the
canvas height, which is not what was reported.
