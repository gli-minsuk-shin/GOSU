# GOSU 0.58.67 candidate

See [maintenance guide](../MAINTENANCE_GUIDE.md) and [release runbook](../RELEASE_RUNBOOK.md).
Adds focused WebContents keyboard handling for AI Assistant in addition to the native menu.
Matches physical keys under Korean/Option layouts, exact modifiers and suppresses repeats/menu
double delivery. Settings now offers explicit modifier/key selectors instead of a read-only recorder.
The existing external shortcut file, default Command+Shift+Space, private data and model choices remain.
This is app-local, not an OS-global hotkey. OS-reserved combinations remain outside GOSU's control.

0.58.66 email task AI drafting is included.
