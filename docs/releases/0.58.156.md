## One unclosed `$$` destroyed a whole answer

Reported from Model Assistant with a screenshot: most of an answer rendered as red error text.

Reproduced exactly. A model opened a display fence with a line that is only `$$` and put the
closing `$$` at the **end of a content line**. That does not close the fence, so remark-math
swallowed every remaining line into one formula, KaTeX refused it with
`ParseError: Can't use function '$' in math mode`, and rehype-katex rendered the entire rest of the
message as `katex-error` source in `#cc0000`. Paragraphs, lists and inline math after it were all
gone.

Three guards now, and every GOSU chat runs all three.

1. **Repair the source before it is parsed.** `repairUnclosedMathFence` walks the lines, skips
   fenced code (a `$$` inside ``` is sample text, not a delimiter), and escapes a `$$` opener that
   never gets a closing line of its own. The rest of the message then parses as what it is, so lists
   stay lists and the inline math after it still renders.
2. **Demote prose that was mistaken for a formula.** A math node that still holds an unescaped `$`
   never was one: remark-math removes the delimiters it matched, so a surviving `$` means the scan
   ran past one. Such a node goes back to text, split on blank lines so the paragraphs survive.
3. **Stop painting failures in alarm red.** KaTeX's default error colour is `#cc0000`. A malformed
   formula is still the user's own words, so it now reads in the surrounding colour and keeps the
   reason in its `title`. A wall of red made a whole answer look broken when only its delimiters
   were.

## The same policy in every chat, which it was not before

The three renderers had drifted apart and only one was ever fixed:

- **Project Chat** and the Markdown document viewer shared `markdown-math-policy.ts`.
- **Model Lab** kept a hand-copied duplicate of the same limits and bounding plugin.
- **Briefing Lab** — the AI 비서, the paper conversations and every insight card — had **no math
  guards at all**: no budget, no strict mode, nothing. The shape that lost a Model Assistant answer
  would have lost a briefing answer the same way.

`markdown-math-policy.ts` is now the one place a formula rule is written. Model Lab re-exports its
old names from it rather than keeping a copy, and Briefing Lab uses it for the first time.
