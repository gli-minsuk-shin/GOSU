# GOSU 0.58.68 candidate

See [task integration](../BRIEFING_TASKS_AND_LIGHTWEIGHT_MODELS.md) and
[release runbook](../RELEASE_RUNBOOK.md).

Email task creation now prepares AI output before opening the editor, like Calendar. Catalog lookup
and lightweight drafting run concurrently; existing edits survive reopening. Project selection is
optional. Personal tasks have `projectId: null`, not a fabricated project, in the encrypted local
workspace. They appear in To-do, Briefing, deadline notifications and recoverable task trash.
Existing project-scoped search remains project-only; personal tasks are accessible via global To-do.
Personal task writes do not enter the project-only Sync API outbox. Apple Reminders export is separate
and still user-reviewed. Clock-time deadlines remain notes/date-only, not timed Reminders alarms.

Nullable ownership is an additive schema change that old binaries do not understand: preserve a
pre-update state backup and do not downgrade a workspace containing personal tasks to an old binary.
Settings, existing project task IDs and ownership remain unchanged. Installation is pending.
