## Usage: what the tokens would have cost on an API key, with prices that update themselves

User request: the Usage view shows tokens only; show, per model, what it would have cost in dollars
on an API key, and make API price changes arrive automatically instead of by hand. The source and
schedule were proposed first (LiteLLM's public list, once a day) and approved ("추천한 걸로 하자").

- **No price is written into the source.** Prices are data: GOSU fetches
  `https://raw.githubusercontent.com/BerriAI/litellm/main/model_prices_and_context_window.json`
  (2.8 MB, about 4,300 entries on 2026-09-21), keeps the first-party Anthropic and OpenAI text
  models at their standard rates (150 entries) and stores them in
  `<userData>/model-prices.v1.json` (mode 0600). A price change in the list reaches the app within a
  day, without a release.
- **Refresh protocol** (`ModelPriceCatalogStore`): at app start when the file is missing or older than
  24 hours, then an hourly check; "가격 새로고침" in the view refreshes now. The request is a plain GET
  of that one fixed URL with `accept` and, once a list exists, `if-none-match`; a 304 confirms the
  list as current. Nothing about the user, the models or the amounts is sent. One request at a time,
  30 s timeout, 16 MB cap, JSON and per-value validation (USD per token between 0 and 1; anything
  else drops that model). A failed refresh keeps the last list and records a stable code
  (`model_prices_network`, `_http`, `_too_large`, `_invalid`, `_empty`, `_storage`), shown in the view.
- **Which price applies** (`modelPriceKey`): Codex ids are the list's own ids. Claude Code records its
  aliases: `claude-code:opus-5` → `claude-opus-5`; a bare family (`claude-code:haiku`, `:sonnet`) →
  that family's newest undated entry in the list (today `claude-haiku-4-5`, `claude-sonnet-5`). The
  card's tooltip names the entry used. A model the list lacks has no price: "가격 미확인", left out of
  the total and counted ("가격 미확인 모델 1개 제외"). Checked against the live list with the ids in the
  local ledger: all priced except `gpt-5.3-codex-spark`.
- **Cost math** (`estimateUsageCostUsd`): cached reads and cache writes are part of the input count
  and reasoning is part of the output count in GOSU's records, so each token is charged once: plain
  input, cached read, cache write, plain output and reasoning output, each at its own rate when the
  list has one and at the plain rate otherwise. Standard rates only: long-context tiers, batch, flex
  and priority rates cannot be told from per-period totals and are ignored. An aggregate without
  reported tokens has no cost (not $0).
- **View**: a first summary card "API 환산 비용" (sum over priced models), a line "API 환산 $…" on every
  model card, and a note with the source, the time of the last successful refresh, the refresh button
  and the failure code when the last refresh failed. Amounts under a dollar keep up to four decimals.
  Without a price list the view is the token report it was. IPC: `gosu:model-usage:prices` and
  `…:prices:refresh`, neither taking input from the page.

This is an estimate for comparison ("API 표준 단가 기준 추정 · 실제 청구 아님"): GOSU runs on
subscriptions, and the list is community-maintained.

Regression tests: `model-price-contracts.test.ts` (new, 4: extraction filter and sanity bounds, id
mapping including bare families, cost math with cache and reasoning rates, totals with unpriced
models), `model-price-catalog.test.ts` (new, 8: fixed URL with no user data and a 0600 file that
survives a restart; a changed price a day later and a 304 confirmation; five failure modes keep the
last list; single flight and start only when stale), `usage-view.test.tsx` (+1: total, per-model
amounts, tooltip, unknown price, source and failure code; nothing shown without a list),
`desktop-app-usage-integration.test.ts` (+1: adapter, main-process start/close, preload calls take no
input).
