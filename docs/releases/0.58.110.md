## One horizontal row for the title, its status and the buttons

User request: align the "개인 연구 브리핑" title, the progress/warning box and the controls beside it
(자동 브리핑, icons) on one horizontal line.

Measured with the real `styles.css` and `workspace.css` in a static page rendering the real progress
component (vertical centre of each element from the header top): while running, and with no status,
the title, progress box and buttons were already on one line (24px). After a run with warnings, the
collapsed warning sat under the buttons, the header grew to 69px and the title moved to 34.5px while
the buttons stayed at 24px, so the title was 10.5px lower than the icons.

Change:

- The collapsed run warning and the paused-schedule line render in the title slot, like the running
  progress (`inSlot` portal); without a slot they stay inside the controls as before. Beside the title
  they look like the progress box, and their opened text floats as a panel under it.
- The title row is at least as tall as the 34px button row, the status slot has a zero flex basis with
  a 160px minimum and does not wrap, each box may shrink with an ellipsis, and the title column takes
  only the width left beside the buttons.

Measured again: with the main panel 1880px and 820px wide, running, with one warning, with a warning
and a paused schedule, with nothing and with an opened warning, the header is 48px and the title,
every status box and the buttons all centre at 24px (two boxes shrink to 164px each at 820px). Only at
600px does the status drop under the title (71px, previously 88–94px), with the buttons still on the
right.
