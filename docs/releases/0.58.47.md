## Behavior and regression coverage

Plans atomically create a fresh goal identity/version, preserve earlier draft/frozen goals, merge
logging with explicit conflict replacement, create an idea and a rules/evaluation session, and record
one durable project/session/attempt receipt. Missing identities remain pending. Comparable runs use
the exact activated goal/entity and immutable logging revision; older ideas can read their original
rules rather than the latest plan. Existing compute approval and JSONL evidence gates are unchanged.

Cavecrew-assisted implementation/review identified and repaired stale-ID/entity-version ABA cases,
snapshot tokens not matching displayed context, negated/review-only intent, missed replay notifications,
late-turn cancellation, target-only dirty drafts and downstream recipe bounds. The Goal editor preserves
unsaved changes during plan updates and explicitly reloads the newer goal only at the user's choice.
Goal/metric schema limits now match the evaluation draft; aggregate input is bounded to 45,000 characters.
