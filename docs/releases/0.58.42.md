## Behavior and safety

- The owned routine's local history view restores all its preserved permission/provider-scope
  conversations in timestamp order. Changing mail query settings or provider no longer hides old
  messages from this local view. Other routines and unowned clients remain inaccessible.
- Model context, original-text search, checkpoints and conversational write approvals still use only
  the current approved scope. The display union is never sent as AI input or treated as authorization.
  A compact notice explains when older-scope messages are display-only. This is not new private-AI consent.
- Existing profile updates retain their position instead of moving to the end and changing the
  desktop bootstrap's default routine after restart. No settings values or permissions are reset.
- While history loads, no new-chat welcome is shown. Restored conversations display first with
  recommendations collapsed. The recommendation icon still opens them explicitly; truly empty chats
  still show the welcome. Restoration errors preserve data and keep sending blocked.
- Read-only restoration retries transient network/process-token/busy errors for at most three
  attempts (400/800ms delay). Permission failures and cancellation do not retry; no AI/action is replayed.
