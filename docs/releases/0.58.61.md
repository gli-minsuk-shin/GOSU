instead of selecting the first regex date. The request uses the displayed email evidence, received
date and saved timezone. It requests a confirmed actionable event, concise title, explicit location
and notes, disclosing inferred year/provisional duration. Unsupported output fails rather than
opening a default today/all-day event. Exact evidence quote, timezone and event range are validated.
Owner/private-AI/Calendar scope and unchanged-profile checks run before and after model execution.
Only the existing editor submission writes an event; drafting does not access or modify Calendar.
