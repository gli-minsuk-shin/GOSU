## SSH workspaces on Claude

User report: "'로컬 SSH 등록된 SSH 서버'에 연결하는 AI가 Codex만 지원하는데 Claude도 지원하게".

- No provider check exists anywhere in the SSH feature: the six `gosu_project` SSH tools are in the
  catalog of every provider, and the Claude Code adapter publishes the same catalog through its MCP
  bridge. Hermes alone does not get them (documented in the architecture).
- The difference was time. A Claude Code turn is one CLI process with a hard deadline that defaulted
  to five minutes, because `startEphemeralThread` never passed `turnTimeoutMs`. One SSH tool call may
  wait five minutes for Allow once plus 120 seconds for the command (`SSH_DYNAMIC_TOOL_TIMEOUT_MS`,
  450 s), so a turn that touched a server was killed while it waited. Codex turns have no such wall
  clock, so remote work only ever finished there. `--max-turns 12` also ended a multi-step remote
  task halfway.
- `projectChatTurnTimeoutMs`: ten minutes plus twice the longest tool wait (25 minutes with the SSH
  tools), capped by the adapter at 30. Providers other than Claude Code ignore the value. The agentic
  turn cap is 40. The per-tool limits and the Allow-once approval are unchanged; on Claude that
  approval is the only gate, as before.
- Known and unchanged: the Claude CLI keeps its own transcript on disk, which includes tool results.

## Instructions for the AI per SSH server

User request: "연결할 때 AI에게 전달할 prompt도 넣자 … minsuk 이라는 이름으로 돌려달라든지".

- Each registered server has "AI 지침" (at most 2,000 characters) under its row in 연결. It is kept
  in `ssh-agent-notes.v1.json` (0600, atomic) and not in the connection profile, because the
  profile's version is part of every trusted-access approval: editing a note there would revoke the
  user's approvals for that server. No SQL changed.
- `list_ssh_workspaces` returns the text as `userNote` for workspaces of that server only. The chat
  policy (version 44) treats a `userNote` as a standing user instruction for work there that never
  grants permission or widens a grant. An unreadable notes file does not block remote work
  (`userNotesUnavailable`), and the editor says so instead of showing an empty box.
- Reading the notes prunes servers that no longer exist; a note for an unknown server is refused.

## Chats open where they were left

User report: "모든 AI chat에서 click 하면 가장 최근 확인했던 부분에서 … 시작하게 하자. 지금은 그냥
아무곳이나 보이는데".

- Project Chat restored `scrollTop` once, in the commit that first rendered the messages, against a
  transcript that math, fonts and tool panes were still growing: a saved offset was clamped short
  and "bottom" meant the bottom of an incomplete transcript. The scroll handler then saved that
  clamped value as the reader's position, so each visit made it worse.
- The assistant chat and the Model Lab chat stay mounted inside frames that the desktop hides with
  `display: none`. Without a box the browser resets their scroll position, and nothing re-rendered
  when the frame came back. Model Lab had no reading position at all and forced the bottom on every
  conversation switch.
- `@gosu/ui/scroll-settle`: `holdScrollTarget` applies the target now and again whenever the layout
  changes, until it has been quiet for 400 ms, the reader scrolls, or four seconds pass;
  `restoreScrollWhenShown` watches the scroller's size and restores on the step from no size to a
  size. While a position is being held it is never saved as the reader's.
- Project Chat opens at the saved offset or at the latest message; the assistant chat and Model Lab
  restore on show; Model Lab keeps a reading position per conversation and opens a conversation
  where it was left. Positions are per run of the app, as before.

## Quote of the day in the title bar

User request: drop "로컬 연구 작업 공간" and show a quote that changes every day, funny or serious, never
repeating the last ten, in the app language.

- The title bar is "GOSU", the version, then one quiet line that shrinks with an ellipsis and never
  pushes the pills on the right; the full text and any note are in the tooltip.
- `DailyQuoteService` answers at once with what it has (a built-in line, the same all day) and
  writes the model's line in the background, once per local day and language. A failure keeps the
  built-in line with its reason and is retried after three hours. A damaged file is left alone.
- The model is the one Settings → Agent assigns to "가벼운 작업"; without one no model is asked.
  GOSU checks the answer itself: language, one line, length, not among the last ten. Authors are
  named only when the attribution is reliable; an original line has none. Usage is recorded as the
  new kind `daily_quote` ("오늘의 격언").
- The model's text is rendered as plain text and never looked up in the message catalog.
