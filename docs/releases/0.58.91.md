models, and the Lecture Studio service was wired directly to the Codex App Server.

Change:

- Routing contract and settings: lecture accepts Codex and Claude Code, like Briefing; Hermes stays
  rejected.
- Lecture Studio receives Codex plus connected Claude Code models, and the service uses the Project
  Chat provider router, which sends `claude-code:*` models to the local Claude Code subscription.
- Claude Code runs a turn in one CLI call without progress notifications, so a Claude lecture turn
  uses only the absolute generation deadline (default 30 minutes) instead of the Codex idle watchdog,
  and requests a matching per-thread CLI limit (`turnTimeoutMs`, clamped to 5–30 minutes; Project
  Chat keeps 5 minutes).
- A routed provider disconnect ends only that provider's lecture turns.
- Claude `claude_code_auth_required` maps to `lecture_auth_required`; `claude_code_timeout` maps to
  an interrupted generation.

Not changed: Hermes is still unsupported for lecture. The idle-watchdog exemption for Claude threads
is not covered by a timer test.
