## Password prompt still shown at every launch

User report after 0.58.102: GOSU still asks for the Mac login password when it is quit and opened
again.

Evidence: the real profile has `local-key.v2.json` written at 22:14 (the first 0.58.102 launch), so the
database key migrated and later launches no longer read `local-key.bin`. The 22:18 launch still
prompted. The 0.58.102 record was wrong that the Overleaf store reads `safeStorage` only when the
feature is used: `desktop-app.tsx` calls `overleafPersonalToken.status()` when the window loads, and
`personalTokenStatus()` decrypts `credentials/overleaf-git/personal-token.bin` with `safeStorage` to
validate the token. This profile has that file (and two linked-project credentials), so every launch
read the Keychain item. The lecture manifest key file does not exist in this profile; it is read only
when a lecture external source manifest is sealed or verified.

Change: `PromptFreeSecretSealing` replaces `safeStorage` for the Overleaf credential store and the
lecture manifest authenticator. It seals with AES-256-GCM under a key derived by HKDF from the
Briefing system key (same helper as the database key, different HKDF label), with a `GOSU-SEAL-v2:`
prefix.

- Startup loads the key before the database opens and the window is created, then re-seals legacy
  `safeStorage` files once in place: `credentials/overleaf-git/*.bin` and the lecture
  `manifest-authentication-key.bin`. This last migration may prompt once.
- Later reads of prefixed files never call `safeStorage` (including `isEncryptionAvailable`, which
  reads the Keychain in Chromium on macOS).
- Unprefixed legacy ciphertext still decrypts through `safeStorage`; a file that fails to decrypt or
  write is left untouched.
- Without the helper, every call falls through to `safeStorage` as before, and a prefixed secret
  throws `local_secret_key_unavailable` instead of prompting.

Rollback note: builds before 0.58.103 cannot read re-sealed Overleaf tokens; the token would have to
be entered again. The pre-install backup holds the legacy files.
