## The quote of the day can be asked for again, and it keeps a history

User request: "title bar에 격언 나오는거 refresh 버튼 누르자 … 생성중일 때는 다른 AI chat에서 작업중일
때 나오는 애니메이션으로 … 하루에 10개 이상의 격언을 refresh하면, 이제 그만하라는 메세지를 격언 칸에
위트있게 … 격언을 클릭하면, 격언 History를 볼 수 있게 … 생성시각과 함께".

- A quiet circular-arrow button sits after the quote. It writes one more line now, with the same
  model Settings → Agent assigns to "가벼운 작업", and the line that is showing stays until the new
  one is written, so the title bar never blinks.
- A line someone is waiting for is looked for every two seconds, not every fifteen as the day's own
  line is, so the new quote appears as soon as it is written.
- While AI writes, the button is replaced by the star that already marks AI work everywhere else in
  GOSU, running at the same rhythm. It is the same component, not a copy.
- Ten a day. The eleventh press asks no model: the quote's own place says "오늘 격언은 여기까지.
  나머지는 실천의 몫입니다." for eight seconds and then the quote comes back, so nothing is lost. The
  button dims and its tooltip says the allowance is spent. A failed attempt also spends one of the
  ten, so a broken model cannot be asked over and over. The count is per local day and survives a
  restart; it starts over at local midnight.
- Clicking the quote opens its history: every line still stored, newest first, with the day and time
  it was written. It opens in the browser's top layer with the quote as its declared invoker, so the
  header cannot clip it, and Escape and a click outside close it.
- The store keeps several lines per day instead of one. A line now carries `createdAt`, the file
  counts hand-asked quotes per day, and up to 200 lines are kept (60 were, when there was one a
  day). Lines written by an earlier version have no `createdAt`; they are ordered by the day they
  belong to and shown in the history like any other.
- A failed refresh leaves the day's lines alone and only records its reason on the line that is
  showing, where the tooltip already explains a built-in line.
- Known: an older GOSU reading this file finds a key it does not know, treats the file as damaged,
  shows its built-in line and leaves the file untouched. Nothing is lost by going back one version.

## The usage chart drops its hatching

User request: "여기서 하한값으로 굳이 빗금 칠 필요있나? 빗금 없애도 되면 없애줘."

- A day was hatched when any turn in it was partial or unreported. In practice almost every day has
  one, so nearly every bar was hatched and the mark separated nothing from nothing while making the
  chart hard to read.
- The hatch, its legend entry and the pattern are gone. The same fact is still stated three times
  where it is useful: in words under the chart, in each bar's own label for a screen reader, and per
  day in the token data table's coverage column, which the chart's subtitle now points to.
