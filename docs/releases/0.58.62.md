# GOSU 0.58.62 candidate

See [release runbook](../RELEASE_RUNBOOK.md) and [global assistant](../GLOBAL_ASSISTANT.md).
Includes pending 0.58.59–61 fixes.

Adds an app-local native menu shortcut for AI assistant, default Command+Shift+Space on macOS.
Settings → 단축키 records a modified combination, explicitly saves it, and restores the default.
The app-owned `assistant-shortcut.v1.json` persists outside the bundle across restart/update.
Main validates the accelerator through trusted main-frame IPC and rebuilds the native menu on save.
Early open events are buffered; repeated shortcuts use existing navigation revision and composer
focus, without resetting conversation history. This is not an OS-wide global hotkey.
