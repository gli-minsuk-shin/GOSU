# GOSU 0.58.9 — 로컬 교체와 유지보수 기준점

날짜: 2026-09-09 (Asia/Seoul).
상태: **로컬 설치 완료**. `/Applications/GOSU.app`의 서명·hash·isolated startup을 확인했고,
실제 실행된 Settings 화면에서 v0.58.9와 10/12/14/16px 옵션을 확인했다.

## 이번 release의 직접 변경

- Desktop/Model Lab의 공통 본문과 입력/controls를 Compact 10px, Default 12px,
  Large 14px, Extra large 16px로 변경했다.
- Settings의 `Aa` specimen과 px 설명은 같은 상수를 사용한다. caption/meta의 예전
  최소 크기 때문에 Compact controls가 본문보다 크게 남는 문제도 제거했다.
- 기존 selected preset과 Model Lab frame/draft를 유지한다. graph canvas의 자체 확대율,
  PDF 내용과 수식의 상·하첨자 비율은 별도다.
- 문서 index, 유지보수 기억, release/rollback runbook, 현재 버전 기록을 추가했다.
  다음 개발 세션은 AGENTS.md에서 이 문서들로 진입한다.

## 알려진 제한 — 설치로 해결되는 것으로 오해하지 말 것

- 최근 Claude 실제 요청은 auth-required였다. 사용자의 재로그인이 필요하다.
- Model Lab Claude native graph-tool namespace 등록의 남은 mismatch를
  [유지보수 가이드](../MAINTENANCE_GUIDE.md#알려진-제한과-후속-보수)에 기록했다.
  이번 설치/문서 작업에서 해당 provider 동작을 수정한 것은 아니다.
- import audit는 arbitrary 모델의 수학적 의미나 gradient를 완전히 증명하지 않는다.
- Briefing의 자료 수집·메일/일정/위치·OS 예약은 미연결이고, 현재 내용은 fixtures다.
  실제 LLM 연결은 루틴 설계/검증에 한정된다. 접속은 `http://127.0.0.1:4318`.
- 이 패키지는 local ad-hoc signed build다. notarized 자동 업데이트 release가 아니다.
  Safe Storage 승인이 필요하면 사용자가 macOS dialog에서 직접 처리한다.
